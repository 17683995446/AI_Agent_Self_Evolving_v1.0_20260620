# 自驱永续进化Agent系统 —— 架构文档

## 系统概览

```
+-----------------------------------------------------------+
|                    SelfEvolvingAgent                      |
|                      (主控制器)                            |
+-----------------------------------------------------------+
|  在线循环 (1Hz)  |  离线循环 (每6小时)                     |
|  +-------------+ |  +-------------+                        |
|  | 环境感知    | |  | 离线优化    |                        |
|  | 多层预测    | |  | 记忆复盘    |                        |
|  | 误差评估    | |  | 健康报告    |                        |
|  | 在线优化    | |  +-------------+                        |
|  | 驱力计算    | |                                       |
|  | 自主决策    | |                                       |
|  | 记忆存储    | |                                       |
|  +-------------+ |                                       |
+-----------------------------------------------------------+
```

## 数据流向

```
[系统状态] --(感知)--> [状态向量] --(预测)--> [预测结果]
                                              |
                                              v
[实际状态] <------------(评估误差)-------------+
   |                                          |
   +-->(在线学习)  +-->(在线优化)  +-->(驱力计算)
                                      |
                                      v
                              [内在动机值]
                                      |
                                      v
                              [自主决策] --(执行)--> [动作结果]
                                      |
                                      v
                              [经验存储] --(记忆系统)
```

## 模块职责

| 模块 | 职责 | 接口 |
|---|---|---|
| EnvironmentPerception | 采集CPU/内存/磁盘/进程状态 | IPerception |
| PredictionEngine | 三层预测：滑动平均/趋势/周期 | IPrediction |
| ErrorEvaluator | 计算MSE/MAE/自由能/惊奇检测 | IErrorEvaluator |
| Optimizer | 在线参数修正 + 离线模型进化 | IOptimizer |
| DriveEngine | 计算安全/收益/能效三大驱力 | IDriveEngine |
| DecisionEngine | 基于驱力选择并执行动作 | IDecision |
| MemorySystem | 短期记忆/长期记忆/优先回放 | IMemory |

## 双闭环运行

### 在线闭环（实时，1秒周期）
1. 感知环境 → 2. 预测未来 → 3. 评估误差 → 4. 在线修正 → 5. 计算驱力 → 6. 决策执行 → 7. 存储经验

### 离线闭环（定期，6小时周期）
1. 复盘历史 → 2. 识别模式 → 3. 模型进化 → 4. 生成报告

        |

|  - 强制休眠                                       |
+--------------------------------------------------+
